# Employee Salary Analysis

A beginner-level Python project that analyzes employee salary data and calculates basic salary statistics.

## Objective

To analyze employee salary data and calculate:

- Total salary
- Average salary
- Highest salary
- Lowest salary

The project also demonstrates how the same salary data can be analyzed using Pandas.

## Technologies Used

- Python 3
- Jupyter Notebook
- Pandas

## Python and pandas Functions Used

- `sum()` – to calculate the total salary
- `len()` – to find the number of employees
- `max()` – to find the highest salary
- `min()` – to find the lowest salary

## Results

|      Analysis      | Result|
|--------------------|------:|
| Number of Employees| 20    |

| Highest Salary     | 65000 |
| Lowest Salary      | 25000 |

## Comparison

The salary values calculated using Python built-in functions and Pandas were compared with the original salary data.

The results matched correctly.

## How to Run

1. Open `Employee_Salary_Analysis.ipynb` in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. Make sure Pandas is installed.
5. View the calculated salary analysis.

- Learned how to create a Pandas DataFrame.
